# ES6 Practice

A collection of JavaScript examples demonstrating ES6+ features.  
Each file focuses on a specific concept to help improve understanding of modern JavaScript syntax and functionality.

## 📁 Files Overview
- **class.js** – Demonstrates JavaScript classes and object-oriented programming.
- **default.js** – Shows how to use default parameters in functions.
- **destructure.js** – Explains object and array destructuring.
- **encapsulation.js** – Implements encapsulation in classes using private fields.
- **inheritance.js** – Covers class inheritance and method overriding.
- **template.js** – Uses template literals for string interpolation.
- **threedot.js** – Demonstrates the spread and rest operators.
